# MM_LLM UI 개편 2026-10 — Console 디자인 전면 적용

`design_handoff_console_redesign`(시안 README·tokens.css·스크린샷)을 앱 전체에 적용한 5단계 개편의 기록이다. 동의·과금·보안 흐름은 위치와 시각만 바꾸고 동작·순서·문구·IPC 인자는 그대로 두었다. 2026-09 개편(중립색 업무 공간)의 기록은 [UI_REDESIGN_2026_09.md](UI_REDESIGN_2026_09.md)에 있다.

이 문서의 캡처와 검증은 **Linux에서 `MM_LLM_MOCK=1` 모의 모드로 실행한 결과**다. 실제 Gateway 호출, 실제 API 키, macOS/Windows 설치본, 서명·공증은 검증하지 않았다. 구분은 [검증 결과](#검증-결과)에 따로 적었다.

### 코디네이터 결정 (Run 중 확정)

| 결정 | 내용 |
| --- | --- |
| A. 화면별 두 번째 열 | 대화 목록 열은 대화·모델 비교 화면에서만 보이고, 다른 화면(설정 240 · 리서치 320 · 미디어 340 · 음성 320 · 프로젝트 260 · 챗봇 260)은 자기 열을 둔다. `⌘/Ctrl+B`는 대화 목록이 없는 화면에서 아무 일도 하지 않고 레일을 숨기지 않는다 |
| B. 계정 진입 | 레일 아바타(`설정·계정`)는 팝오버 없이 설정 화면의 **계정 · API 키**를 연다. 업데이트·크레딧·로그아웃·키 교체·모델 새로고침은 설정 화면으로 옮겼다. `data-testid="update-status-live"` 라이브 리전은 앱 전체에 하나만 둔다 |
| keep-alive | ChatPanel(`.chat-slot`)과 MediaPanel(`.media-keepalive`)은 다른 화면에서 `hidden`+`inert`로 살아 있다. 진행 중 답변·초안·첨부가 화면 이동으로 끊기지 않고, 유료 미디어 결과가 사라지지 않는다. 숨은 화면의 단축키(Escape 중지·`⌘↑`·숫자키)는 꺼지고, 포커스가 숨은 화면 안에 있으면 현재 레일 항목으로 옮겨진다 |
| 음성은 keep-alive 하지 않음 | 음성 화면을 떠나면 기존처럼 세션을 종료하고 저장하지 않은 확정문을 폐기한다(마이크·과금 세션이 숨은 채로 남지 않게 함) |

## 변하지 않은 것

- 첨부 비식별 확인 모달(선택·드롭·기록 세 진입점), 비교·미디어 첨부 동의 체크, 음성 과금·저장 동의 문구와 비활성 규칙, 의미 색인 동의·재개 확인, 위험 동작의 취소 기본 포커스.
- CSP 문자열, `sandbox`, `contextIsolation`, 내비게이션·창 열기 차단, `trustedInvoke`, 키 입력 `type=password`. 새 네트워크 origin 없음. 새 IPC 채널은 테마 push(`appearance:resolved`, main→renderer)뿐이고 설정 IPC는 허용 키 3개와 값 검증만 추가했다. `undefined` 값은 "없음"으로 취급하되 잘못된 형식·알 수 없는 키는 계속 거부한다.
- 최초 세로형 창 비율, 마지막 창 크기 복원, 저장 형식과 백업 형식.

## 5단계에서 한 일

- **상태 시트**: 버튼 5종(주요·보조·텍스트·위험·비활성/중지), 입력 3상태(기본·hover/포커스·오류), 세그먼트·토글·체크박스, 배지, 메뉴, 안내 박스를 시안 13/14와 나란히 대조해 `styles.css`의 상태 레이어로 정리했다.
- **후속 보정**: ★ 즐겨찾기 버튼을 리스트박스 밖으로, 종합분석 안내의 답변 글자 수, 미디어 비식별 확인 행의 중복 체크 표시 제거, 음성 헤더 한 문장화, 한글 모노 간격, 프로젝트 헤더 표준화, 설정 업데이트 행·푸터, 미디어 바쁨 안내 문구 단일화(죽은 `busyRefusal` prop 제거), 사용하지 않는 CSS 제거.
- **R-4 Low**: 드롭 중 세션 종료 시 남은 임시 첨부 폐기(L1), 겹친 저장에서 거절된 기본 지침 저장의 대기·재시도(L2), 설정 IPC가 명시적 `undefined`를 없음으로 취급(L3), 미디어 바쁨 문구 공유(L4), keep-alive 포커스·`⌘↑` 테스트 강화(L5, 이전 커밋 `cbbf270`에서 실패함).
- **`scripts/ui-smoke.mjs`**: 개발 전용 스모크. `build.files`가 `out/**`만 포함하므로 배포에 들어가지 않는다. 제품 코드에는 테스트 훅이 없고 Chromium 표준 `--remote-debugging-port`와 CDP(기존 `ws` 의존성)로 마우스·키보드 이벤트만 보낸다. 테마·글자 크기도 실제 설정 화면을 눌러 바꾼다.

### 스모크 실행

```bash
npm run build
systemd-run --user --scope -p MemoryMax=4G -p MemorySwapMax=0 --quiet -- \
  env NODE_OPTIONS=--max-old-space-size=3072 timeout 300 \
  npm run ui:smoke -- --stage 5 --shots <캡처 폴더> --fonts medium
```

`MM_LLM_MOCK=1`, 개인 임시 `TMPDIR`, mock 키 `mock-key`만 사용한다. Chromium 샌드박스가 설정되지 않은 호스트에서는 첫 실행이 즉시 종료되며, 스크립트는 모의 모드에 한해 `--no-sandbox`로 한 번 다시 시도한다(제품의 창 옵션 `sandbox: true`는 그대로). 로그인 화면은 로그인 전에 먼저 캡처한다. 옵션: `--viewports`, `--themes`, `--fonts`, `--screens`, `--no-states`. 한 번에 300초를 넘기지 않도록 글자 크기별로 나누어 실행했다.

### 새·강화된 회귀 테스트

모두 합성 데이터이며 삭제·약화된 테스트는 없다(미디어 `busyRefusal` 테스트는 prop을 제거한 L4에 맞춰 문구·죽은 prop 검사로 교체했고, 합쳐져 있던 keep-alive 테스트는 숫자키와 `⌘↑`로 나누어 더 강하게 만들었다).

- ★ 버튼은 리스트박스 밖·같은 행, 종합분석 안내의 답변 글자, 미디어 비식별 행 체크박스 1개, 음성 헤더 한 문장, 7가지 업데이트 상태의 푸터·행, 드롭 중 로그아웃 시 폐기, 기본 지침 저장 대기·재시도(구 코드에서 실패 확인), 설정 IPC `undefined`, keep-alive 포커스·`⌘↑`(구 `cbbf270`에서 실패), 프로젝트 헤더의 `⌘K` 검색.
- 정적 검사: 평면 버튼·상태 레이어, 52px 헤더 규칙, 한글 모노 규칙, 스모크 스크립트가 배포 제외·모의 전용·제품 훅 없음.

### 실제 환경에서 확인하지 않은 것

- 실제 ChatKHU Gateway 호출과 실제 모델·권한: 모든 화면은 모의 데이터이고 크레딧 숫자(880 / 1,000)는 예시다.
- macOS·Windows 설치본 화면, 서명·공증, 업데이트 다운로드·설치(모의 실행에서는 업데이트가 꺼져 있다).
- CI 결과: 로컬 결과만 있다.
- 음성 "마이크 사용 중" 상태: 과금을 피하려고 세션을 열지 않았다. 대기 상태만 캡처했고, 모의 모드에는 실시간 음성 모델이 없어 모델 select가 "사용 가능한 모델 없음"으로 보인다.
- 시안 스크린샷과의 비교는 사람이 나란히 보는 방식이다(픽셀 diff 아님).

## 남은 항목

- **L6 프로젝트 '미디어' 탭**: 미디어 작업(`PendingMediaJob`)에 대화·프로젝트 연결 정보가 없어 "해당 대화의 미디어 작업" 목록을 만들 수 없다. 가짜 목록 대신 설명문을 보여 준다. 연결 필드를 저장하려면 작업 저장소 형식 변경이 필요하므로 **이번 개편의 범위 밖**으로 기록하고, 미디어 작업은 미디어 화면의 작업 목록에서 확인한다.
- 범위 밖으로 둔 것: 다중 창(`⌘↵` 새 창), 비교 결과의 대화 스냅샷 저장(인라인 비교는 앱을 다시 시작하면 모델 비교 화면 목록에서만 보인다), 미디어 결과 자동 프로젝트 보관, 자동 로그인 옵션, 시간 기반 자동 테마, 폰트 서브셋·코드 분할, 저장·백업 형식 변경, 음성 세션 실제 과금 캡처.
- 시안의 메뉴 단축 글자(P·R)는 대응하는 단축키가 없어 표시하지 않았다.
- `custom-check` 스타일은 더 이상 쓰이지 않지만 `ui:audit`의 컨트롤 경계·변조 검사가 이 이름을 참조해 남겨 두었다. 검사 이름을 바꿔 등록할 때 함께 정리한다.
- 기본 지침 저장 대기 중 설정 화면을 완전히 벗어나면(앱 전체 화면 전환) 대기 중인 입력은 저장되지 않는다. 화면 안의 카테고리 이동은 입력을 보존한다.
- 개발 호스트에서는 Chromium 샌드박스 설정이 없어 스모크가 `--no-sandbox`로 재시도한다. 이는 스모크 프로세스에만 해당한다.
