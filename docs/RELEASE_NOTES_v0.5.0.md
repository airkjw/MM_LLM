# MM_LLM v0.5.0

대화와 연구에 집중할 수 있도록 화면 구성을 전반적으로 새롭게 정리했습니다. 보라색 중심의 디자인을 흰색·회색 바탕과 파란색 강조로 바꾸고, 메뉴와 조작부의 구분을 명확하게 했습니다.

## 달라진 화면

- **대화:** 상단에는 제목과 모델을 표시하고, 웹 검색·사고 강도·대화 설정은 입력창에 모았습니다. 답변의 읽기 폭과 시작 가이드 배치를 정리했습니다.
- **사이드바:** 작업 공간·미디어·최근 대화를 구분하고 검색을 상단에 배치했습니다. 사이드바를 접어도 아이콘으로 주요 기능에 접근할 수 있습니다.
- **모델 비교:** 비교 설정을 접고 결과에 집중할 수 있습니다. 넓은 창에서는 답변을 나란히, 좁은 창에서는 세로로 보여주며 진행 상태를 한글로 표시합니다.
- **모델 선택:** 모델명 중심으로 목록을 정리했습니다. 모델 ID는 검색과 툴팁으로 확인할 수 있습니다.
- **미디어:** 작업 설정과 결과 영역을 구분하고 장식용 소개 영역을 줄였습니다.
- **로그인·설정:** 로그인 화면을 새롭게 구성하고 API 키 보기·숨기기를 추가했습니다. 앱 설정은 테마·글자 크기·기본 지침을 먼저 보여주고, 백업·복원과 진단 정보는 펼쳐서 사용합니다.

## 접근성과 화면 대응

- 라이트·다크 테마의 색상과 초기 창 배경을 맞췄습니다.
- 접힌 사이드바에서 대화상자를 닫으면 사용하던 버튼으로 키보드 포커스가 돌아옵니다.
- 접힌 상세 설정의 숨은 버튼으로 키보드 포커스가 이동하지 않도록 개선했습니다.
- 최소 글자 크기, 색 대비, 포커스 표시, 동작 줄이기 및 고대비 모드 지원을 유지했습니다.
- 처음 실행할 때의 세로형 창 비율과 마지막 창 크기·위치 복원은 그대로 사용할 수 있습니다.

## 설치 및 업데이트

- 기존 사용자는 앱의 업데이트 기능으로 설치할 수 있습니다. 대화 기록·설정·API 키는 기존 방식으로 보관됩니다.
- Apple Silicon Mac: `MM_LLM-0.5.0-arm64.dmg`
- Intel Mac: `MM_LLM-0.5.0.dmg`
- Windows x64: `MM_LLM-0.5.0-x64-Setup.exe`
- macOS 설치 앱은 Developer ID 서명과 Apple 공증을 거칩니다. Windows 설치파일에는 별도의 Authenticode 서명이 적용되지 않습니다.
