# MM_LLM v0.6.0

앱 전체를 새 Console 디자인으로 바꾸고, ChatKHU의 웹 검색·논문·법령 리서치·프로젝트 의미 검색·코드 실행·실시간 음성 기능을 연결했습니다. 동의와 과금 안내는 기존 문구를 그대로 쓰고 위치만 바뀌었습니다.

## 새 화면 구성

- 왼쪽 얇은 레일에서 대화·모델 비교·논문·법령 리서치·미디어·음성·프로젝트·챗봇·설정·계정으로 이동합니다.
- 두 번째 열은 화면마다 바뀝니다. 대화 화면은 대화 목록을, 설정·리서치·미디어·음성·프로젝트·챗봇은 각 화면의 열을 보여 줍니다.
- `Ctrl+K`(macOS `⌘K`)로 명령 팔레트를 열어 대화 검색, 새 대화, 모델 비교 시작, 화면 모드 전환, 크레딧 새로고침을 할 수 있습니다.
- 시작 화면에 주제 카드 4개가 있습니다. 입력창에 포커스가 없을 때 `1`–`4`로 바로 시작합니다.
- 새 글꼴(Pretendard, JetBrains Mono)을 앱에 포함해 인터넷 연결 없이도 같은 화면으로 보입니다.
- 라이트·다크·시스템 화면 모드와 글자 크기 3단계(작게·기본·크게)를 지원하고, 좁은 창(640px 폭)에서도 화면이 넘치지 않습니다.

## 대화와 모델 비교

- 입력창 안의 모델 칩으로 모델을 고릅니다. 모델이 2개 이상이면 전송할 때 비교로 실행되고, 결과가 대화 안에 최대 3열로 나란히 표시됩니다.
- 모델 선택 창에서 `⇧↵`는 비교에 추가, `⌥↵`는 즐겨찾기입니다. 줄마다 ★ 버튼도 있습니다.
- 첨부가 있고 모델이 2개 이상이면 입력창 아래에 기존 첨부 전송 동의 체크박스가 나타나며, 체크해야 전송할 수 있습니다.
- 비교에서 웹 검색을 쓰면 Sonar 공통 검색이 실행되는지, 추가 요청이 발생하는지를 입력창 아래 경로 안내에 항상 표시합니다.
- 모델 비교의 종합분석 안내는 실제로 검토·과금되는 답변만 표시합니다.

## ChatKHU 기능

- **웹 검색**: 모델이 자체 검색을 지원하면 그대로 사용합니다. 지원이 확인되지 않거나 지원하지 않는 모델은 첫 유료 호출 전에 Sonar 추가 요청이 발생함을 안내합니다. 딥리서치는 호출 상한을 함께 보여 줍니다.
- **논문·법령 리서치**: 계정에서 쓸 수 있는 검색 도구를 직접 확인한 뒤 실행하고, 고른 결과만 대화의 근거로 붙입니다.
- **프로젝트 의미 검색**: 동의한 경우에만 프로젝트 문서를 의미 기반으로 찾습니다. 색인은 이 기기 안에 암호화해 보관합니다. 백업에는 원본과 추출 본문만 담기며, 복원 후 색인은 다시 만들어야 하고 복원만으로는 원격 호출을 하지 않습니다.
- **코드 실행**: 지원 모델에서 고급 설정으로 켤 수 있습니다. 코드는 제공사 서버에서만 실행되고 이 기기에서는 실행되지 않습니다.
- **실시간 음성·받아쓰기**: 음성 화면에서 기존 동의 항목을 확인한 뒤 사용합니다. 음성 화면을 떠나면 세션이 종료되어 마이크가 숨은 채로 켜져 있지 않습니다.

## 설정과 안정성

- 설정은 저장 버튼 없이 바로 저장됩니다. 화면 모드·밀도·동작 줄이기·단축키 힌트를 설정할 수 있습니다.
- 계정 기능(API 키 교체·로그아웃·모델 목록 새로고침·업데이트 확인)은 설정 › 일반 / 계정 · API 키로 옮겼습니다.
- 다른 화면으로 이동해도 진행 중인 답변, 보내지 않은 초안, 첨부가 유지됩니다.
- 미디어 생성 중 다른 화면으로 이동해도 과금된 결과와 크레딧 갱신이 누락되지 않습니다.
- 기본 지침 저장이 다른 저장과 겹친 상태에서 설정 화면을 떠나도, 앞선 저장이 끝난 뒤 저장됩니다.

## 업데이트 후 확인

- 기존 대화·프로젝트·설정은 그대로 이어지며 이전 백업도 그대로 복원할 수 있습니다.
- macOS Apple Silicon: `MM_LLM-0.6.0-arm64.dmg`
- macOS Intel: `MM_LLM-0.6.0.dmg`
- Windows x64: `MM_LLM-0.6.0-x64-Setup.exe`
- macOS 앱은 Developer ID 서명과 Apple 공증을 거칩니다. Windows 설치파일에는 별도의 Authenticode 서명이 적용되지 않습니다.
