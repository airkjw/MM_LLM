# MM_LLM v0.6.3

업데이트 설치가 늦어질 때의 안내와 배포 자동화를 정비했습니다.

## 업데이트 설치 안내

- `업데이트 설치`를 누른 뒤 2분이 지나도 앱이 그대로 열려 있으면 "업데이트 설치가 아직 시작되지 않았습니다"라는 안내가 한 번 나타나고, 설치 버튼을 다시 누를 수 있게 됩니다.
- macOS에서는 설치 준비가 오래 걸릴 수 있습니다. 안내가 나온 뒤에도 준비가 끝나면 앱이 스스로 종료되며 설치될 수 있으니 작업을 저장해 두세요.
- 이전처럼 앱을 종료하면 준비된 업데이트가 자동으로 설치됩니다.

## 그 밖의 변경

- 논문·법령 리서치의 검색 도구(MCP)에 연결할 때 앱의 실제 버전을 알리도록 고쳤습니다. 이전에는 예전 버전 번호(0.5.1)가 고정돼 있었습니다.
- 빌드·배포 자동화(GitHub Actions)를 최신 실행 환경으로 옮겼습니다. 앱 기능에는 변화가 없습니다.

## 업데이트 후 확인

- 기존 대화·프로젝트·설정은 그대로 이어집니다.
- macOS Apple Silicon: `MM_LLM-0.6.3-arm64.dmg`
- macOS Intel: `MM_LLM-0.6.3.dmg`
- Windows x64: `MM_LLM-0.6.3-x64-Setup.exe`
- macOS 앱은 Developer ID 서명과 Apple 공증을 거칩니다. Windows 설치파일에는 별도의 Authenticode 서명이 적용되지 않습니다.
