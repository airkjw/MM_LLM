# MM_LLM v0.6.2

업데이트가 준비됐는데 설치 버튼을 찾기 어려웠던 문제를 고쳤습니다.

## 업데이트 설치 경로 수정

- 업데이트가 준비되면 왼쪽 레일 아래 계정 버튼에 "업데이트" 표시가 붙습니다. 이 버튼을 누르면 설정 › 일반이 열리고 `업데이트 설치` 버튼으로 바로 이동합니다.
- 설정 화면 아래의 "업데이트 준비됨" 표시도 누르면 바로 설치됩니다.
- 설치 버튼을 여러 번 눌러도 설치 요청은 한 번만 보냅니다. 요청이 실패하면 다시 누를 수 있습니다.
- 업데이트 확인 중 오류가 나면 계정 버튼이 설정 › 일반으로 열려 다시 확인할 수 있습니다.
- 이전처럼 앱을 종료하면 준비된 업데이트가 자동으로 설치됩니다.

## 업데이트 후 확인

- 기존 대화·프로젝트·설정은 그대로 이어집니다.
- macOS Apple Silicon: `MM_LLM-0.6.2-arm64.dmg`
- macOS Intel: `MM_LLM-0.6.2.dmg`
- Windows x64: `MM_LLM-0.6.2-x64-Setup.exe`
- macOS 앱은 Developer ID 서명과 Apple 공증을 거칩니다. Windows 설치파일에는 별도의 Authenticode 서명이 적용되지 않습니다.
