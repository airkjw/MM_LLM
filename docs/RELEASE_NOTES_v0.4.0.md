# MM_LLM v0.4.0

## 새 기능

- 대화·프로젝트 문서·설정의 암호화 백업과 복원을 지원합니다. API 키는 백업에 포함하지 않습니다.
- 모델 즐겨찾기와 최근 사용 모델로 자주 쓰는 모델을 빠르게 선택할 수 있습니다.
- 답변마다 사용 모델과 생성 시각을 표시하고 대화 내보내기에 포함합니다.
- 종합분석 결과를 복사하거나 Markdown으로 저장할 수 있습니다.
- API 키·대화 내용·개인 파일 경로를 제외한 진단 정보를 복사할 수 있습니다.

## 사용성 개선

- 모델 선택창의 키보드 탐색과 확인창의 포커스·접근성을 개선했습니다.
- 오류·안내·성공 메시지를 구분하고 배경 작업 오류를 별도로 표시합니다.
- OCR 진행 상황, 문서 발췌 범위, 만료된 파일 및 차단된 링크를 안내합니다.
- 창 너비를 바꾸어도 사용자가 접은 사이드바 상태를 유지합니다.

## 안정성 개선

- 프로젝트 변경 후 첨부 전송 동의를 다시 확인할 수 없던 문제를 수정했습니다.
- 화면 갱신으로 미디어 조회가 불필요하게 반복되던 문제를 수정했습니다.
- 수동 크레딧 새로고침이 자동 조회에 흡수되지 않도록 했습니다.
- 저장 한도를 사전에 확인하고 저장 실패 시 기존 기록을 보존하도록 개선했습니다.
- 네트워크 대기 시간 제한과 로그인 확인 취소를 추가했습니다. 과금 생성 요청은 자동 재전송하지 않습니다.

## 이용 안내

- 백업은 최대 512MB이며 12자 이상의 별도 암호가 필요합니다. 암호를 분실하면 복원할 수 없습니다.
- 미디어 생성물과 비교 실행 기록은 백업 대상에서 제외됩니다. 일반 대화 첨부는 기존 저장 내용으로 보존됩니다.
- macOS는 Apple Silicon용 `arm64.dmg`, Intel용 `.dmg`를 선택하세요.
- Windows는 `x64-Setup.exe`를 사용하세요. Windows 설치파일에는 별도의 Authenticode 서명이 적용되지 않습니다.
