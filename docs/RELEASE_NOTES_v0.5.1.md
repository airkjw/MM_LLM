# MM_LLM v0.5.1

짧은 첨부 문서가 불필요하게 잘리던 문제를 수정하고, 모델 비교의 첨부 확인과 실행 상태를 알아보기 쉽게 개선했습니다.

## 첨부 문서 처리 수정

- 전송 한도에 충분히 들어오는 짧은 문서도 앞부분 1,500자만 전달되던 문제를 수정했습니다.
- 첨부 문서의 추출된 본문 전체가 전송 한도에 들어오면, 관련도에 따라 일부를 제외하지 않고 원래 순서대로 모두 전달합니다.
- 일반 대화·후속 질문·모델 비교에 공통으로 적용됩니다. 한도를 넘는 자료는 기존처럼 관련 부분을 발췌합니다.
- 문서 전체 전달과 발췌 기준에 대한 화면 안내를 보완했습니다.

## 모델 비교 사용성 개선

- 첨부 전송 동의 체크박스가 보이지 않던 문제를 수정했습니다.
- 첨부 동의 전에는 비교 실행 버튼을 비활성화하고 필요한 확인 항목을 안내합니다. 첨부가 없는 질문은 동의 없이 실행할 수 있습니다.
- 첫 답변이 나오기 전에도 비교 준비 중이라는 상태를 표시합니다.
- 비교와 워크스페이스 도구의 오류를 열린 창 안에 표시합니다.
- 비교 연결을 시작하는 단계에서 예외가 발생하면 실행 대기 상태를 해제하고, 첨부 자료를 유지해 다시 시도할 수 있도록 했습니다.

## 업데이트 후 확인

- 이전 버전에서 문서가 압축되었다는 안내와 함께 받은 답변은 전체 문서를 검토한 결과가 아닐 수 있습니다. 업데이트 후 파일을 다시 첨부해 새 비교 또는 새 질문으로 분석해 주세요. 기존 답변은 자동으로 다시 생성되지 않습니다.
- macOS Apple Silicon: `MM_LLM-0.5.1-arm64.dmg`
- macOS Intel: `MM_LLM-0.5.1.dmg`
- Windows x64: `MM_LLM-0.5.1-x64-Setup.exe`
- macOS 앱은 Developer ID 서명과 Apple 공증을 거칩니다. Windows 설치파일에는 별도의 Authenticode 서명이 적용되지 않습니다.
